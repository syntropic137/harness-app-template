# Project anchors (fill in per project)

The template ships this file as a placeholder. Each project replaces it with its own anchors so a restarted Architect needs nothing else.

| Anchor | Value |
|---|---|
| PM session to report to | _session name_ |
| Bead store and actor | _e.g. `br`, `--actor <name>`_ |
| Architect beads | _ids_ |
| Owned ADRs | _ids and paths_ |
| Layer map | _path_ |
| Fitness config | _`APSS.yaml`, sensors baseline, `vsa.yaml`_ |
| Ratchet files | _every floor or budget file; each needs the same relaxation guard_ |
| Land command | _e.g. `just land`_ |
| Last measurement | _date, crate graph, module cycles, depth, gate times_ |
